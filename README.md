# Page Translator · 网页翻译

独立的 Chrome / Edge Manifest V3 扩展。使用自己的模型 API 翻译网页，默认双语对照，可切换仅译文或恢复原文。无需后端。

## 安装使用

首次从仓库获取后，先安装依赖并构建（Node.js 22+）：

```sh
git clone https://github.com/hugh-zhan9/page-translator.git
cd page-translator
npm ci
npm run build
```

构建产物 `dist/` 不纳入 Git。构建完成后加载扩展：

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择 **`page-translator/dist`**，不是项目根目录。
4. 打开扩展的「API 设置」，填写配置并点击「保存并授权 API」。
5. 点击「测试已保存配置」确认连通，再到普通网页点击扩展 →「翻译当前页」。
6. 普通网页右下角默认显示小「译」按钮。点击展开，再点「翻译」开始并自动收起面板；随时可重新展开或按 Esc 收起。可以点击「关闭此网站」隐藏，刷新或重开该网站仍保持关闭；要重新显示，在扩展弹窗点击「在此网站显示悬浮按钮」。按钮支持切换显示方式和「恢复原文 / 停止」。
7. 弹窗选择「双语对照 / 仅显示译文」；点击「恢复原文」结束本页翻译会话。

更新构建后，需要在扩展管理页点「重新加载」，然后刷新已翻译的网页，避免旧 content script 留在页面中。

### 此次指定的优先配置

| 字段 | 值 |
|---|---|
| API 类型 | OpenAI 兼容 · Responses |
| API Base URL | `https://api.fengwind.com` |
| 模型 | `translate` |
| 目标语言 | 简体中文 |
| API Key | 自行填写；项目中不包含真实 Key |

实际请求为 `POST https://api.fengwind.com/responses`，不会自动插入 `/v1`。此配置已通过合成短文本真实调用，也从真实浏览器中的扩展后台返回了「你好，世界。」；这不代表所有网站或所有文本的翻译质量已经验证。

其他服务：支持 OpenAI Chat Completions 和 Anthropic 原生 Messages。OpenAI 的 Base URL 原样作为接口前缀；要求 `/v1` 的服务应自行在地址中包含它。Anthropic 默认地址 `https://api.anthropic.com`、默认模型 `claude-opus-5-5`，由官方 SDK 处理原生路径。模型名均可修改。

## 行为与隐私

- 目标语言为中文时，中文或以中文为主的片段沿用原文，不提交给模型。判定忽略网址、邮件地址、数字和标点，兼顾品牌、其他文字体系以及所配置的简繁体规则。
- 手动开始，多个段落合并请求，最多同时 3 个请求；每请求不超过 16 个文本片段、12000 字符，逐段显示。40 个短段落的受控测试使用 3 次请求，实际耗时取决于服务商和文本长度。仅发送文本，不发送网页 HTML、Cookie、图片或表单输入值。
- 保留原 DOM 元素、链接事件和图片；切换或恢复不重新请求翻译。结合语义段落与 CSS 显示方式分组，正文中的行内链接与前后文字共用一段译文；译文中的对应链接文字保留可点击链接和下划线，地址来自原链接，不由模型生成，标题中的链接也同样可用。相对地址和页内锚点随页面路由解析，原链接地址变更会同步，不额外请求翻译。新增译文链接支持 HTTP/HTTPS、邮件和电话地址；不复制脚本 URL 或原节点事件，特殊脚本驱动控件仍需使用原入口。译文尽量保留整段/局部加粗、斜体、下划线、删除线、高亮、上下标、文字颜色、字体字号、行高和显式换行，支持格式与链接嵌套；源格式或窗口尺寸变化时刷新缓存显示，不增加翻译请求。仅投影文字格式，不复制定位、宽高、间距、背景图片或脚本，复杂布局和伪元素不保证一致。标题、导航、页脚链接和独立短标签使用 `原文（译文）` 旁注；正文在段落下显示。按原页面规则处理空白，避免源码缩进撑高页面；纯数字和相同译文不重复展示。代码、隐藏内容、编辑区及 `translate="no"` 不参与。
- 开始后，新出现或修改的普通文本也会被翻译。恢复原文后停止观察；迟到结果不会重新改写页面。已经发出的 API 请求可能仍产生费用，恢复并不保证撤销该费用。
- Key 保存于 `chrome.storage.local`，不云端同步，不向 content script/网页提供，设置读取不回显。**本机存储不是加密保险箱**。网页文本会发送给配置的服务，请遵守内容外发要求及服务商政策。
- 为默认显示入口，扩展声明 `activeTab`、`scripting`、`storage` 和普通 HTTP/HTTPS 主机权限；浏览器可能提示更新后的站点访问权限，仍可在扩展管理中限制。后台只调用已保存的完整 API 地址。
- 悬浮入口默认显示，显示本身不扫描或外发正文。关闭偏好只保存在本机，按当前协议与精确主机生效（不含子域，端口不区分）；关闭会恢复原文并隐藏入口，弹窗可重新开启。旧逐站动态脚本在更新时清理，未保存关闭偏好的网站采用新默认。
- 不自动重试、不切换模型或供应商。超时、拒绝、截断和格式错误会显示失败，保留相应原文；已经成功的其他段落保留，可恢复全部。
- 支持普通 HTML 主文档及可识别、可访问的同源邮件正文阅读框。阅读会话会跟随换信，处理正文中的普通段落和纯文本邮件；纯文本正文按空行拆分翻译，继续跳过显式标记的代码、明显的代码声明、隐藏内容和编辑区。收件箱主题译文随栏位宽度紧跟原文或在主题栏内另起一行。固定高度的行不会被译文遮挡，可悬停查看插件提供的中英提示（不覆盖站点已有提示），或切换仅译文。跨域或隔离沙箱阅读框、通用 iframe、PDF、图片 OCR、Shadow DOM、浏览器内部页面和扩展商店页面不在支持范围；复杂富文本与特殊页面布局未做全面兼容验证。
- 切换 API 来源或协议时必须重新填写 Key；同来源同协议留空表示保留。清除配置会删除本机 Key；已授予的浏览器主机权限可在扩展管理页另行撤销。

## 开发与验证

环境：Node.js 22+（本机使用 26.8.2），npm。依赖版本固定并保留 lockfile。

```sh
npm ci
npm run check                 # 类型检查、单元测试、构建
npx playwright install chromium
npm run test:browser          # 本机受控 API + Chromium 扩展集成验证
node scripts/mutation-check.mjs
```

使用已安装浏览器时，设置 `BROWSER_PATH` 为可执行文件路径。例如 macOS Edge：

```sh
BROWSER_PATH='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' npm run test:browser
```

`test:browser` 创建并清理独立临时配置，不使用你的默认浏览器资料。按 manifest 的默认权限真实加载扩展，只访问本机受控页面/API，操作设置页及同一份 popup 文档，验证双语、紧凑标题/导航/页脚、390px 窄屏、默认悬浮入口、关闭持久化/重新开启、动态内容、还原、监听器保留和 content script 密钥隔离。无头模式下 popup 文档放在独立标签页而非工具栏浮层；原生权限提示、浏览器站点访问限制及完整手工安装体验需要人工确认。截图保存在 `test-results/`。

`live-api-test.mjs` 是显式调用真实 API 的可选脚本，需在进程环境中提供 `LIVE_BASE_URL`、`LIVE_MODEL`、`LIVE_API_KEY`（不要把 Key 写入脚本或提交）。测试配置仅保存占位值，真实 Key 由测试进程在请求时注入，测试结束清理临时浏览器配置。不在普通测试中读取凭据或调用真实付费服务。

- 2026-11-16 源文字格式增量：最终 55 项单元测试、类型检查和构建通过；Chromium 151.0.7922.34 / Edge 157.0.4341.60 受控集成验证实际字体粗细、嵌套斜体、文字装饰、高亮、上下标、颜色字号、显式换行及 390px 响应式字号，模式切换和还原不追加请求，两者页面错误为 0。截图见本机 `test-results/source-format-bilingual.png` 和 `source-format-mobile.png`，使用预设译文而非真实供应商。

## 代码入口

- `src/background.ts`：设置、可信消息、API 权限及调用。
- `src/config.ts`：配置和消息边界校验。
- `src/provider.ts`：Responses、Chat Completions、Anthropic 及翻译结果校验。
- `src/page.ts`：原 DOM、分块、显示模式、动态内容与恢复。
- `src/content.ts`：隔离世界中的页面会话入口。
- `src/sites.ts` / `src/floating.ts`：默认入口、按站点关闭偏好、权限重查与页面悬浮工具。
- `src/options.ts` / `src/popup.ts`：设置页及弹窗。
