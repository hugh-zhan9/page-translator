# 网页翻译插件详细设计

状态与来源沿用[概要](概要设计.md)。2026-11-14 已完成链接分组、紧凑排版及默认悬浮入口变更，44 项单元测试、类型检查、构建及 Chromium / Edge 受控集成通过。独立审查发现的问题已补充先失败后通过的回归并修复，限定范围复核未发现剩余显著问题。本轮未调用真实供应商，浏览器原生站点访问限制未实机验收。2026-11-16 已完成译文可点击链接和源文字格式保留，55 项单测、类型检查、构建、21 项定向变异及 Chromium / Edge 受控集成通过；审查发现的相对地址同步和纯换行包装丢失问题已补充回归并修复，限定修正复核无剩余发现。具体证据与限制见 [README 的当前验证证据](../../../../README.md)。

## 数据与调用

配置存储：provider（openai / anthropic）、baseUrl、model、targetLanguage、apiKey。设置查询只返回非密钥字段和 hasApiKey。Key 输入留空表示保留当前同来源 Key；清除配置为显式操作。更改来源且未提供新 Key 则拒绝保存。设置页负责申请该 API 来源权限，后台保存及调用前再验证权限。

扩展消息使用带类型对象。可信 popup/options 可 getSettings、saveSettings、clearSettings；顶层 content script 可 translate（仅文本数组）而无配置访问。返回 `{ok:true,data}` 或 `{ok:false,error}`，不得透传包含 Header/Key 的原始异常。页面文本及译文不持久化。

文本请求合并多个段落的片段，长文本按 Unicode 字符边界拆分，单片不超过 2400 个 UTF-16 单元，单请求不超过 16 片和 12000 个 UTF-16 单元。输出必须是 JSON 对象中的 translations 字符串数组，数量严格匹配输入；空值、非字符串、拒绝或截断失败。分块不截掉原文。输出用 textContent / Text.data，不允许 innerHTML。OpenAI 兼容协议由用户选择 responses 或 chat/completions；请求路径直接追加到 baseUrl，不隐式插入 /v1。用户指定的 Responses / translate 优先验收；真实短文本请求已在根 /responses 返回 HTTP 200、status=completed，output 中的 JSON 带单层 Markdown 围栏，解析器允许这一明确格式。Anthropic 使用官方 SDK messages 接口。模型名允许用户配置；Anthropic 默认 claude-opus-5-5，不隐式改用其他模型。

## DOM 与会话

扫描器读取主文档和已识别的同源邮件阅读框中的可见普通文本节点；优先保留 p、标题、列表项等语义段落的边界，其余依据计算后的 CSS display 分组。正文内的行内链接及其包装（含 inline-flex 的块级子元素）归入周围段落；独立 flex/grid 项、导航链接和没有直接正文的 inline-block 项分别管理，避免混成一份译文。段内独立空格、标点和数字保留，但不单独请求翻译；没有字母/文字的容器不创建翻译记录。每段保存原 Text 节点引用、原文本、分片索引和返回译文。保留行内元素及节点监听器，不 clone 或重建原子树。

双语布局遵循 [D-002](概要设计.md#D-002)。渲染层根据原容器 white-space 处理输出：normal/nowrap 折叠普通 ASCII 空白、去除外部缩进；pre-wrap 等保留有意换行。标题及独立链接/行内项用括号旁注，导航/页脚内不超过 120 字符的短项也用旁注；正文使用块级译文。规范化后与原文相同的译文不添加显示节点，仍保留翻译状态与模式切换所需数据。

2026-11-16 链接与源格式修正沿用节点索引：NodeText 记录原生 a 归属；translatedView 只投影受管理文本的祖先路径和可见的 br（含只有换行的行内包装），以结构化 TextView 表达译文、标签、白名单样式及链接属性。strong/b/em/i/u/s/del/ins/mark/small/sub/sup 保留语义，其余包装转为行内 span；原定位、宽高、间距、类名、ID、事件和背景图片不复制。TEXT_STYLES 限定字体、行高、字间距、颜色/背景色、文字装饰、上下标位置和 white-space；计算样式通过 style.setProperty 写入，文本通过 createTextNode 写入，不解析模型 HTML。空白依据对应原文本父元素的 white-space 处理，保留片段间分隔和内层 pre-wrap。原节点和监听器不复制或重建。

链接地址用原节点解析后的协议检查，仅 HTTP/HTTPS、mailto、tel 可用于新增链接；复制原 href 属性以保留相对路径及页内锚点，随 history 路由和 base 与原链接一致解析；只复制 target、rel、download、referrerpolicy、title，移除 opener 并加入 noopener。不重复投影段落外的原 a，也不代点原链接。链接属性、class/style 或结构变化通过现有扫描比较完整显示快照，只重绘缓存译文；会话期间的 resize 也触发有界扫描，停止时移除监听。原文本或链接归属变化仍使旧段落记录失效。受保护内容和隐藏换行不进入投影。

| 状态 | 事件 | 可见结果 |
|---|---|---|
| 未开始 | 开始 | 创建会话、扫描及翻译 |
| 进行中/已完成 | 切换模式 | 已完成段落重新呈现，未完成内容不隐藏 |
| 进行中/已完成 | 站点变更 | 弃用受影响段落旧结果，新内容重新进入扫描 |
| 任意会话 | 恢复 | 停止观察、移除自有译文、还原未被站点覆盖的修改 |
| 已恢复 | 旧请求返回 | 丢弃，不再修改 DOM |

重复开始不能创建重复 observer 或译文。空集合不请求模型。错误数和成功段落数在 popup 可见；不将失败文本作为翻译结果。

观察目标为 Document，覆盖 body 替换；扫描使用固定窗口的有界调度，持续变化不能无限推迟扫描。自有 DOM 写入前通过 takeRecords 保留尚未投递的站点变化，再断开观察，避免误观察自身写入。隐藏过滤包含祖先 content-visibility:hidden，以及未打开 details 中除首个 summary 外的内容；open 属性变化会触发扫描。

## 本轮接口增量

默认静态注入由 manifest 拥有；后台 chrome.storage.local 的 disabledSites 数组保存按协议/精确主机关闭的 pattern。可信 popup 可 getSite(tabId)、setSite(tabId, enabled)，后台读取实际 tab URL 并验证 pattern；顶层 content script 的 siteStatus 仅返回自身站点的 enabled 与 permitted，disableSite 只能关闭 sender.url 所属站点，忽略调用方传入的地址或 tabId。站点偏好写入与权限重查串行处理。偏好关闭停止当前站点翻译；权限重查仅在 permitted=false 时停止，不能因另一网站撤权而中断隐藏按钮站点的手动翻译。启动清理旧 pt-site-* 动态注册，不迁移 API 配置。详情由 [D-004](概要设计.md#D-004) 拥有。

文本分块可在一次请求中包含多个段落，各片保存对应段落、节点索引。每次收到结果时完成已有全部分片的段落，不等待其他长段；失效段落不能阻断同批未变段落。[D-005](概要设计.md#D-005) 拥有请求调度边界。

## Verification Strategy

- TC-01：构建清单检查及真实 Chromium 扩展加载。
- TC-02 / TC-05 / TC-06：DOM 单元测试，以及真实浏览器页面脚本/链接监听器不被破坏、动态追加、恢复、迟到结果的回归。
- TC-03：两类 API 受控本地服务，断言协议、数量校验、错误与超时；不访问真实收费 API。
- TC-04：配置/发送者校验单测，以及真实扩展存储访问权限与按来源授权验证。
- TC-07：指定 Responses / translate 的真实合成短文本及浏览器扩展后台调用成功；真实 Key 通过测试进程在内存中注入，未写入测试浏览器配置。
- TC-08：真实 Chromium / Edge 中验证默认显示、不自动发文本、刷新、真实翻译/关闭按钮点击、关闭持久化和弹窗重新开启；权限拒绝及跨站撤权隔离由受控单元测试验证，浏览器原生站点访问限制需人工确认。均不依赖真实供应商。
- TC-09：批量段落对应、3 请求并发上限、单批失败与源文变化回归。
- 对计算及状态条件的主证据做破坏性变体测试（仅临时测试源码副本，不更改交付结果）。

## Planning Handoff

用户范围固定；模块文件划分和构建工具属于实施选择。无需再建执行计划。没有尚待用户裁定的业务选择。真实供应商连通性、翻译质量和扩展商店发布不在当前自动化证据内；不得称已通过。安全敏感代码完成后须独立审查精确 diff，发现重要缺陷后修复并复核。
