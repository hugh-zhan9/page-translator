# 网页翻译插件概要设计

状态：产品范围已由用户确认；下述为据此采用的实现方案，不代表另有人工架构审批。2026-11-12 已实现首版，类型检查、27 项单测、Chromium / Edge 受控集成及指定 Responses 真实调用已执行；独立审查的 4 项重要问题已修复，针对修复及相关交互的独立浏览器复核未发现剩余 Important/Critical 问题。来源：[原始确认需求](../../../../.loopx/intake/2026-11-12-web-translation/requirements.md)。字段与验证见[详细设计](需求设计文档.md)。Support lenses：architecture-designer。

## 组件与信任边界

<a id="D-001"></a>
**D-001 · Interface / Data Contract · 实现方案（AC-01、AC-03、AC-04）**：使用 Manifest V3，由扩展后台拥有配置及 API 调用；设置页只向后台保存和读取脱敏配置；content script 只拥有页面 DOM 和翻译会话。无新增后端，无 Suhui 运行时依赖。

```text
使用者 → 弹窗 / 设置页 ──可信扩展消息──→ 后台 service worker
             │                              │
             │ activeTab 按次注入             ├─ 本机 storage.local（禁止非可信上下文访问）
             ↓                              └─ 用户配置的模型 API（仅获准来源）
          content script ──文本翻译请求───────↑
             │
             └─ 当前主文档：原节点、译文及页面会话
```

网页不是可信调用者。后台按 sender 的扩展 ID、扩展页面 URL 或顶层 tab 身份限制消息种类；不开放外部消息或网页 window.postMessage 桥。API 地址仅从后台配置取得，不能由页面翻译请求指定。按 2026-11-14 用户要求，普通 HTTP/HTTPS 主页面默认静态注入悬浮入口，后台管理按站点关闭偏好与实际主机权限；具体由 [D-004](#D-004) 拥有。API 仍只请求保存的完整地址，站点文本仅在用户开始翻译后发送。

Suhui 的 HTML 分块和双语合成值得借鉴，但它操作阅读器 HTML 字符串，且依赖 Electron IPC、safeStorage 与数据库；不能直接用于活网页。其 AGPL/GPL 和图标限制使复制代码带来独立许可要求，因此本项目独立实现。

## 翻译与还原

<a id="D-002"></a>
**D-002 · Behavior Contract · 实现方案（AC-02；2026-11-14 根据用户排版反馈更新）**：保留原 DOM 元素；按段落内文本片段分块，译文通过文本节点显示，不执行模型输出。双语模式按内容位置展示：正文在完整段落下方显示译文；标题、导航/页脚链接及独立短标签在原文后显示括号旁注（如 `Trending（热门）`），允许随可用宽度自然换行，不强制另起译文块。纯数字及与原文相同的译文不重复展示。显示时遵守原文的 CSS 空白规则，不能把 HTML 源码缩进变成大片空白。仅译文模式修改受管理文本节点；恢复只还原仍属于当前会话的修改。切换和恢复不额外请求模型。变更由现有 `src/page.ts` 的采集/渲染负责，不增加站点专用分支、API 协议或持久状态；原链接节点、事件、受保护内容和失败行为保持不变。Support lenses: none。

2026-11-16 译文链接修正（用户要求，沿用 D-002）：双语译文按已有文本节点对应关系重建可点击链接，地址取自原 DOM，不由模型生成，也不向模型额外发送地址或 HTML。同一原链接的连续文字合为一个译文链接；输出已经位于原链接内时不嵌套链接。链接保持行内展示、沿用原链接颜色并加下划线，普通 HTTP/HTTPS（含相对路径、页内锚点）、mailto、tel 使用浏览器原生导航；不复制脚本 URL、事件处理器、ID、class 或原子树，不代理原链接点击事件。原链接的事件仍留在原节点。仅脚本驱动或其他协议的特殊控件不新增可执行入口。模式切换及还原不增加 API 调用，原链接地址变化时同步译文地址。实现局限于 page.ts，无新服务、消息协议或持久状态；链接渲染与安全边界须测试并独立审查。

同日追加的源格式要求仍由 D-002 / page.ts 渲染层承担：根据受管理文本节点的祖先关系投影安全的行内格式，而不是拼接纯文本或复制完整 DOM。保留加粗/斜体/下划线/删除线/高亮/上下标等语义、文字颜色/字体/字号/行高和显式 br 换行，支持其与链接嵌套；CSS 字体格式使用计算样式白名单，不复制定位、尺寸、间距、背景图、类名、ID 或事件。原链接安全规则、正文对照、标题旁注、模型仅返回文本和不增加翻译请求保持不变。格式变化及窗口尺寸变化通过现有扫描刷新缓存显示。复杂布局、伪元素和完整样式表复刻不属于文字格式投影；不能承诺所有网站像素一致。

```text
手动开始 → 读取设置与 API 权限 → 扫描可翻译文本
  ├─ 空集合 → 显示“没有可翻译内容”
  └─ 非空 → 有界分块 → 逐块请求
       ├─ 合法结果且源节点未变化 → 更新显示 / 继续下一块
       ├─ 请求失败 → 记录失败、该部分保持原文 / 继续其他段落
       └─ 会话已停止或原文已变化 → 丢弃迟到结果
```

会话期间观察主文档新增或修改文本；恢复时停止观察并使旧请求结果失效。站点自行重写、移动或删除节点时不得把旧译文写回新内容。保护代码、表单、编辑区、隐藏内容及 translate=no。同源可见邮件阅读框由顶层会话统一收集和观察，沿用同一个分批调度器、显示模式与停止操作。跨域/隔离沙箱、通用 iframe、PDF 和 Shadow DOM 不处理。

## 密钥、失败和安装边界

<a id="D-003"></a>
**D-003 · Operational Contract · 实现方案（AC-03、AC-04）**：Key 本机保存、不云端同步，不提供“加密保险箱”承诺；界面明确网页文本将发送至用户所选 API。默认手动触发，不自动重试、切换供应商或降级模型。请求超时、响应缺项、拒绝或截断按失败处理。已有成功段落保持，失败段落保留原文并可恢复全部。

仅允许 HTTPS API，HTTP 仅用于回环本地服务；拒绝 URL 凭据、查询、fragment，拒绝重定向以避免 Key 转发。切换来源必须重新提供 Key。Anthropic 使用官方 SDK，关闭 SDK 自动重试，不开启供应商或模型 fallback。

首版以开发者模式加载本地构建目录，不包含商店发布。自动化本地受控服务验证两类请求；真实供应商费用和真实网页发送需要用户另行授权。

## 本轮增量：合并请求与按站点悬浮入口

<a id="D-004"></a>
**D-004 · Interface / Operational Contract · 用户确认默认显示（AC-06，2026-11-14 替代逐站启用）**：manifest 在普通 HTTP/HTTPS 主文档默认注入 content.js 并声明对应主机权限。后台继续拥有站点状态，改为 chrome.storage.local 中精确协议/主机的关闭偏好；缺省启用，不包含子域，Chrome 主机权限仍不区分端口。弹窗可关闭/重新开启当前网站，悬浮控件提供“关闭此网站”按钮。content script 仅新增关闭自身站点的消息，不接受 URL、tabId 或任意启用操作，后台从可信 sender.url 决定目标；Key 和设置仍只对可信扩展页面开放。关闭停止当前站点会话、还原原文并移除入口；刷新后保持关闭，不影响其他站点。仅显示入口不扫描或发送正文，真实用户点击翻译才开始。浏览器限制站点访问时尊重其权限，不自动重新申请。

旧 pt-site-* 动态注册在安装/更新及启动时清理，避免与默认静态脚本并存；旧记录不包含关闭信息，未存关闭偏好的网站按新默认显示。站点写入仍由 sites.ts 串行处理，沿用后台通知和 content.ts 的来源过滤。关闭列表与 API 设置分开存储，无新服务或跨模块依赖。安全边界变更须独立精确差异审查。

```text
普通网页加载 → 静态注入 → 查询自身站点偏好与权限 → 显示入口或保持关闭（不翻译）
真实用户点击翻译 → 现有 PageTranslation 会话 → 现有后台 API 调用
关闭此网站 → 后台保存关闭偏好 → 同站点页面还原并隐藏
弹窗重新开启 → 后台移除关闭偏好 → 同站点页面显示入口
```

<a id="D-005"></a>
**D-005 · Behavior Contract · 实现选择（AC-07）**：页面调度一次选取最多 16 个待处理段落，合并其文本片段并仍按每请求 16 片 / 12000 字符拆包，最多同时 3 个请求。每片保持段落和节点索引，源节点变更只淘汰对应结果，不挂住同批其他段落。请求失败影响该请求包含的段落，不自动拆包重试；之前已完成段落不回滚。提速证据区分“请求数减少”和“真实模型耗时”，不能把受控延迟测试当成供应商延迟承诺。
