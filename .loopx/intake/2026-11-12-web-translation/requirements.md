# 网页翻译插件首版需求

状态：用户已确认产品范围；首版及批量请求/逐站悬浮入口已实现，自动化已完成；指定 API 为首版历史验证，安装交互及完整网站兼容性的人工确认范围见 README。来源：2026-11-12 用户原始请求及五项问答。参考项目为 Suhui，但不得改动它。

## 已确认范围

- AC-01：独立浏览器扩展，首版支持 Chrome / Edge。
- AC-02：翻译当前网页内容，默认在原文正文段落下显示译文；可以切换仅译文，并恢复原文。2026-11-14 用户根据标题、导航、仓库卡片及页脚截图追加排版要求：标题译文紧跟原文，避免统一另起一行撑大页面；短标签采用紧凑对照，正文保留段落对照，修复源码空白造成的异常高度。2026-11-16 用户追加：译文中的链接文字也应保留链接样式并可点击，不能只保留原文链接；仍保持完整段落对照和紧凑标题。同日用户继续要求“同样加粗我也需要保留，总之就是尽可能保留源格式”：译文应尽量保留对应原文的文字格式，而不只保留链接；包括整段/局部加粗以及其他常见行内格式，不以复制源布局破坏已有紧凑排版。
- AC-03：支持 OpenAI 兼容接口和 Anthropic 原生接口，使用者配置 API 地址、模型与 Key。用户追加优先验收：其指定网关的 Responses API（wire_api=responses）、模型 translate 必须优先打通；OpenAI 接口同时可选择 Responses / Chat Completions。凭据不记录在本文。
- AC-04：使用者自行提供 Key，插件直接调用配置的模型 API，无需配套后端。
- AC-05：以合成短文本真实验证用户指定的 Responses 端点；不使用真实网页、不保存测试凭据。
- AC-06：2026-11-14 用户改为“悬浮按钮默认显示，可以手动关闭”。普通 HTTP/HTTPS 主页面默认显示入口，用户点击翻译才读取/发送正文。按当前网站记住关闭状态，刷新或重开仍关闭，可从扩展弹窗重新开启。为默认注入申请普通网页访问权限，仍遵守浏览器站点访问限制。此要求替代 2026-11-12 的逐站授权后显示模式。
- AC-07：合并多个段落进入同一次 API 请求，在保持段落与行内文本对应的前提下减少往返；限制单请求项目数与文本总量，长页分批完成。

## 必要实现约束

手动点击才开始发送网页文本；默认目标语言为简体中文，可在设置中修改。按文本分块翻译，不发送整页 HTML、Cookie 或表单输入。保留链接、图片、代码和原节点事件；API 失败时显示错误，不用错误文本替换原文。Key 不传给网页或 content script，不写日志，不使用云端同步；本机扩展存储不是加密保险箱。Suhui 仅作机制参考，不复制其代码、图标或素材。

2026-11-23 用户反馈邮件正文漏译、中文重复和界面遮挡。阅读时需包含可识别的同源正文框及纯文本邮件；中文目标跳过已是中文的片段，列表中的主题保留在各自栏位，悬浮工具默认收起。原有普通 HTML 主文档和动态文本继续支持。不包含 PDF、图片 OCR、跨域 iframe、封闭 Shadow DOM、浏览器内部页面、自动站点规则、云端账号和扩展商店发布；这些不是对普通网页翻译承诺的替代。

## 验收场景

| 场景 | 对应要求 | 可观察结果 |
|---|---|---|
| TC-01 安装与页面入口 | AC-01 | 构建出 MV3 扩展，可在 Chromium 加载，弹窗和设置页可操作 |
| TC-02 双语、仅译文和还原 | AC-02 | 普通段落与行内链接保留，双语译文的对应链接文字有链接样式且可点击到原地址，加粗及常见行内文字格式尽量与原文对应，标题仍紧凑；切换及还原不重新请求 API，原节点身份不变 |
| TC-03 两类协议 | AC-03 | 受控 HTTP 服务收到对应格式；合法结果显示，缺项、拒绝、截断和 HTTP 失败不伪造成功 |
| TC-04 配置与 Key 边界 | AC-04 | 用户设置可保存；网页消息不能读取/修改设置，content script 不持有 Key；后台按保存地址调用 API 并验证浏览器实际权限 |
| TC-05 边界和异步 | AC-02 | 空页、单段、长段落、动态追加内容有明确状态；恢复后迟到结果不重新插入译文 |
| TC-06 失败与受保护内容 | AC-02、AC-03 | 错误可见；代码、隐藏内容、编辑区和 translate=no 不送出；部分已完成段落可保留，失败部分保留原文 |
| TC-07 指定网关可用性 | AC-03、AC-05 | Responses / translate 的合成短文本真实调用返回有效翻译；从扩展后台再次验证，不落盘真实测试凭据 |
| TC-08 默认悬浮入口 | AC-06 | 普通网页默认显示且不发文本；点击才外发；关闭当前网站后恢复并隐藏，刷新保留关闭，弹窗可重新开启；不同站点偏好隔离，浏览器权限限制仍生效 |
| TC-09 合并与并发 | AC-07 | 40 个短段落以 3 次请求完成；单请求上限不变，最多 3 个在途请求；同批内容失效不影响其他段落，失败保留原文 |

## 验证边界

自动化受控 API 验证不代表真实模型翻译质量或真实供应商连通性。没有授权就不读取已有凭据，不发送真实网页到收费服务，不发布扩展，不提交或推送 Git。
